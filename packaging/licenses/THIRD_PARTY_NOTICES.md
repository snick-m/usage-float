https://download.qt.io/archive/qt/6.8/6.8.3/single/

Build and licensing information:
https://doc.qt.io/qt-6.8/build-sources.html
https://doc.qt.io/qt-6.8/licensing.html

The deployed shared libraries can be replaced with ABI-compatible versions;
Usage Float does not use static Qt linking. Source for this application and its
build scripts is available at https://github.com/snick-m/usage-float.
